## 📖 About This Repository

This repository demonstrates a **complete end-to-end Machine Learning pipeline** — starting from understanding raw data all the way to deploying trained models.

All experiments are implemented in **Jupyter Notebooks** and run on **Google Colab** — no local setup required. Each notebook follows a clean academic format:

> **Aim → Theory → Implementation → Visualization → Results & Conclusion**

</details>

<br>

- Building a simple predictive model
- Model evaluation using MSE and R² score

</details>

<details>

- Multi-feature prediction models
- Correlation analysis between features

</details>

<details>
<summary><b>🔹 Exp 05 — Decision Tree Classification</b></summary>
<br>

- Tree-based decision making
- Feature importance ranking
- Full decision tree visualization

📌 *Goal: Build interpretable and explainable ML models*
</details>

<details>
<summary><b>🔹 Exp 06 — Naïve Bayes Classification</b></summary>
<br>

- Probabilistic classification using Bayes' theorem
- Multi-class classification
